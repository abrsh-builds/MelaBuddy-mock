# MelaBuddy (መላBuddy) - React Native JavaScript (.jsx) Student Budget App

Pure React Native app written entirely in **JavaScript using `.jsx` files**.

## 🚀 Quick Setup Instructions

1. Open this folder in **VS Code**.
2. Open terminal (`Ctrl` + `~` or `Cmd` + `~`) and install packages:
   ```bash
   npm install
   ```
3. Run Expo in tunnel mode:
   ```bash
   npx expo start --tunnel
   ```
4. Scan the QR code using the **Expo Go** app on your phone!
